# To-do-sistem
**Sistema To-Do (PHP/Java)**: Solução **Full-Stack** com **Login**, **CRUD de Tarefas** e persistência em **MySQL**. Inclui **Painel Admin** e geração de **Relatórios em PDF**. Frontend em **HTML/CSS** para design responsivo. Foco em modularidade, **segurança** e gerenciamento eficiente de dados.
